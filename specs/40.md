## Problem

The first real use needs the whole chain proven on the target host, end to end: the pinned quenching operator agent, `quenching-mcp` launched by `uvx`, the server policies and the model allowlist.

## Proposal

Deploy with `deploy.sh` and run a smoke with a short live session on the operator agent. The smoke checks:

- `/specs:status` answers through `quenching-mcp`;
- the verifier sub-agent is denied a write (the rule matches `edit`, the name OpenCode reports);
- a server policy denies a marker shell command inside a sub-agent session;
- a model outside the allowlist is refused;
- the budget blocks above its hard limit.

The cost of the live calls is estimated before and measured after. The results are recorded in `## Discoveries`, with `<server-host>` and never the host's address.
